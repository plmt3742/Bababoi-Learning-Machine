# 00 · 项目速览

## 一句话

把一道错题变成三道同类题，并追踪掌握度的 AI 错题巩固平台。

仓库：https://github.com/plmt3742/Bababoi-Learning-Machine

## 产品闭环

```text
录入错题（文本/图片）
   ↓
AI 分析（知识点、题型、错误原因）
   ↓
生成 3 道相似题（题干 + 答案 + 解析）
   ↓
练习（作答、计时、自评/判分）
   ↓
统计（正确率、薄弱知识点、近期趋势）
   ↓
回到“录入/练习”，形成闭环
```
