## 3. M1：纵向切片（11.8–11.14）

### 3.1 目标

跑通一条**真实可演示的纵向切片**，并部署：

```text
登录 → 录入一道文本错题 → AI 分析 → 生成 3 道题 → 保存 → 列表/详情可见
```

图片录入 v2 在 M1 只做**接口 spike**（能上传裁剪图片、DeepSeek 返回 1..N 道题文本），完整多题条目/选择交互放 M2。

### 3.2 工作重点

| 方向 | 重点 | 不要做 |
|---|---|---|
| 后端 | 用户/错题/生成题数据模型；JWT；CRUD；LLM 客户端；JSON 校验；分析/生成接口；图片上传 + 多题文本提取 spike；种子脚本 | 完整多题交互、统计、复杂推荐 |
| 前端 | 应用壳/路由/登录；API client；录入页（先文本）；列表/详情；生成中/失败状态；Markdown+公式渲染 | 高保真动画、暗色模式、移动端深度适配 |
| 部署 | 11.12 前有 staging 地址；nginx + API + MySQL；CORS/环境变量 | Kubernetes、复杂监控 |
| 协作 | 11.8 冻结 API v1；每天 15 分钟同步；11.14 联调验收 | 私自改字段不通知 |

### 3.3 M1 退出检查

## 4. M2：功能完整（11.15–11.21）

### 4.1 目标

P0 全部可用，主流程无阻塞 bug；P1 按剩余时间做。

### 4.2 工作重点

- 练习模式（P0）：作答、计时、查看答案、自评、记录。
- 三种题型 + 工具栏（P0 增强）：选择/填空/解答；LaTeX/编号/表格/插图按时间降级。
- 任务中心 + 草稿（P0）：列表 + 状态 + 失败重试 + 草稿行；服务端 + localStorage 双写。
- 学习统计/概览（P1）：错题数、练习数、正确率、薄弱知识点、趋势。
- 搜索/筛选/标签：按学科、标签、关键词；分页。
- 错误态/空状态/加载态：AI 超时、额度不足、JSON 失败、无数据。
- 图片录入 v2（P0 增强）：电脑粘贴/拖入、手机相册/拍照 → 用户裁剪 → DeepSeek 提取 1..N 道题文本 → ① ②… 条目逐条确认 → 分析/答案/解析 → 选择 1–3 道生成。
- 体验：响应式、键盘操作、对比度、移动端至少三页可用；手机录入入口必须可用。
- 性能：列表不返回全文；索引；N+1 检查；AI 超时/重试。

### 4.3 M2 退出检查

- [ ] P0 功能逐项通过 `02-goals.md` 的验收清单。
- [ ] 练习记录写入/统计数字一致（统计 P1）。
- [ ] 三种题型可创建/显示/编辑；工具栏基础功能可用。
- [ ] 任务中心列表/状态/失败重试/草稿行可用；草稿双写可恢复。
- [ ] 搜索/筛选/分页在 100+ 条数据下正常。
- [ ] 图片入口可用：电脑粘贴/拖入、手机相册/拍照；上传前裁剪；多题条目 ① ②… 逐条确认；提取失败可退回文本；不丢输入。
- [ ] AI 失败有提示和重试；不白屏、不产生脏数据。
- [ ] MySQL 部署环境通过完整回归。
- [ ] 完成一次用户走查（产品评审 + 1–2 名同学），反馈有记录和取舍。

## 7. 进度更新规则

1. **每天收工前**：更新 `04-todos.md` 的状态；把阻塞项写到“阻塞”区。
2. **每周日**：更新本文件的“当前进度”；检查里程碑退出条件；调整下周计划。
3. **里程碑结束**：更新 `00-context.md` 的“当前阶段/下一步”；写一条变更记录。
4. **延期处理**：任何任务延期超过 1 天，必须写原因、影响、补救方案；不要默默拖。
5. **范围变更**：新增 P0 功能必须同时删掉一个同等工作量的 P0，或在 ADR 中记录为什么加。
