## 3. 示例：录入错题页（可照着填）

```text
页面名称：录入/编辑
路由：/questions/new
目的：把一道错题录入、识别/分析、显示、编辑、保存；保存后后台整理/生成
主操作：保存
次操作：切换输入方式、题型、保存草稿、取消
布局：
  - 顶部：页面标题 + 返回
  - 输入方式：Tab「文本 / 图片」
  - 题型：选择/填空/解答
  - 文本：题干编辑器 + 选项/空位/答案 + 工具栏
  - 图片：粘贴/拖入/上传 + 原图预览 + AI 预框 + 确认
  - 右侧/下方：学科、章节、标签
  - 底部：保存 + 提示
组件：PageHeader、Tabs、Form、QuestionEditor、EditorToolbar、Select、TagInput、ImageInput、ImageFrameConfirm、ImagePreview、Button、DraftBar
数据/API：
  - 草稿：GET/PUT/DELETE /drafts/me
  - 文本/编辑：POST /questions（保存后自动入队 analysis）
  - 图片：POST /questions/from-image（先框题返回候选，确认后再识图）→ 编辑 → POST /questions
状态：
  - draft：本地/服务端草稿恢复
  - detecting：AI 正在框定题目区域；显示原图 + 进度 + 取消
  - confirming：原图高亮框 + “是这道题吗？”；可确认/切换候选
  - vision：裁剪后识图中；显示进度 + 取消
  - editing：编辑器；KaTeX 错误标红不丢内容
  - saving：保存中
  - saved：入库 + 任务入队，跳任务中心/详情
  - error：框题/识图/保存失败显示错误码 + 重试；保留草稿
交互：
  - 题干 ≤ 5000 字；答案 ≤ 5000 字；学科必选；标签 ≤ 10
  - 图片 JPEG/PNG/WebP：前端选图 ≤20MB；压到 ≤5MB/2000px；上传 ≤10MB
  - 电脑：Ctrl+V 粘贴 / 拖入 / 点击上传；手机：拍照、相册两个入口
  - 两端 AI 框定核心题目后，用户确认/切换候选；P0 不做拖拽画框
  - 识图结果按题型模板填入编辑器；用户确认后才创建错题
  - 离开页面时三选项：取消退出 / 保存草稿 / 直接退出
校验：题干必填（或识图结果非空）、长度、学科必选、题型结构（选项/空位）、图片类型/大小
权限：登录用户
响应式：移动端单列；主按钮固定在底部；手机拍照/相册入口在首屏可见
验收标准：
  - 3 分钟内完成录入 + 保存（文本或图片）
  - 三种题型可编辑；工具栏基础功能可用
  - 框题确认可一键确认/切换候选；框题失败可退回整图识图或文本
  - 识图失败可重拍/换图/改文本，不丢输入
  - 保存后任务入队；重复点击不会创建多条错题
```

## 4. 关键页面要点

### 4.1 首页

- P0：录入入口、最近错题 3 条、任务中心入口、练习入口。
- P1：4 个核心数字（错题数/练习数/正确率/连续天数）、薄弱知识点 Top 3、趋势图。
- 空状态：引导“录入第一道错题”。
- 不要堆 6 个图表；统计 P1 先不做图。

### 4.1b 录入/编辑器（P0，三种题型 + 工具栏）

- 题型：选择题（2–24 项）、填空题（`___` ≤20 空）、解答题。
- 显示/编辑：默认渲染态；单击进入编辑态；失焦防抖 400ms 自动渲染。
- 工具栏：文本样式、列表、LaTeX 模板、编号、表格/插图按时间降级。
- 保存：题干非空；选择题 ≥2 项；填空题每空有答案。
- 草稿：服务端 + localStorage 双写；见 `docs/product/06-draft-dual-write.md`。
- 失败：KaTeX 错误标红不丢内容；保存失败保留草稿。

### 4.2 错题列表

- 筛选：学科、标签、关键词；URL 同步，可分享/刷新保留。
- 卡片：题干摘要（2–3 行）、学科、标签、生成题数、时间。
- 空状态 vs 筛选无结果要区分。
- 删除：二次确认；软删除；列表即时移除。
- 分页：默认 20；超过 100 条再考虑虚拟列表。

### 4.2b 图片录入（P0 增强）

- 电脑：Ctrl+V 粘贴 / 拖入 / 点击上传；显示原图预览、文件大小、删除/重拍。
- 手机：底部动作面板“拍照 / 从相册选择”；拍照用 `capture="environment"`。
- 两端都走 AI 框题：原图高亮最可能的核心题目，提示“是这道题吗？”；用户可确认/切换候选，P0 不做拖拽画框。
- 状态：detecting（框题中）→ confirming（待确认）→ vision（裁剪后识图）→ 按题型模板填入编辑器。
- 识图：显示“正在识图”阶段；结果按题型模板填充（题干/选项/空位/答案），原图并排对照。
- 失败：重拍/换图/直接粘贴文本；不要只弹 toast。
- 含图题：显示“图形描述”，提示生成题以纯文本变体为主。

### 4.3 错题详情/生成

- 上方：原题 + 答案（折叠）+ 分析（知识点/题型/难度/错误原因）。
- 下方：3 张生成题卡；答案/解析默认折叠。
- 主操作：“生成相似题”；生成中显示阶段进度。
- 失败：错误说明 + 重试 + “返回编辑”。
- 已生成：可“重新生成”（P0 基础版：单题图标 + 二次确认 + 队列替换）、“去练习”、“报错”。

### 4.4 练习（P0）

- 一次一道题；顶部进度（1/3）+ 计时。
- 作答区：文本域/选项（按题型）。
- 提交后：显示答案 + 解析 + “会/不会”。
- 结果页：本次正确率、用时、薄弱点提示。
- 退出确认；重复提交禁用。

### 4.5 统计/概览（P1）

- 4 个数字 + 1 个趋势图 + 薄弱点列表。
- 0 练习：空状态“先去练习 1 道题”。
- 数据口径与后端一致（正确率 = 正确数/总数）。
- 图表不要显示空坐标系；无数据时用空状态。

### 4.6 登录/注册

- 单页切换登录/注册；最少字段。
- 错误：用户名/密码错误、用户名已存在、网络错误。
- 登录成功跳 `redirect` 或首页。
- 不做找回密码/邮箱验证（P1）。

### 4.7 任务中心（P0）

- 列表：题目摘要、题型、整理状态、生题状态、时间。
- 状态：排队中/生成中/完成/失败；失败行有【重试】。
- 草稿行：顶部置顶；摘要 + 更新时间 + 【继续编辑】。
- 不做复杂筛选/通知/批量操作。
- 点击行进入详情；失败重试调用 `POST /tasks/{id}/retry`。

## 5. 通用状态规范

| 状态 | 表现 | 必须有 |
|---|---|---|
| loading | 骨架屏/按钮 loading | 不阻塞整个页面；可取消长请求 |
| empty | 插画/图标 + 一句说明 + 主操作 | 告诉用户下一步 |
| filter-empty | “没有符合条件的错题” + 清空筛选 | 不要和空账号混淆 |
| error | 错误说明 + 错误码（可选）+ 重试 | 不白屏；不丢输入 |
| partial | 已成功部分 + 失败提示 | 可重试缺失部分 |
| success | 明确结果 + 下一步 | 不要只弹 toast |

## 6. 响应式检查

| 宽度 | 检查 |
|---|---|
| 375px | 单列；底部导航；主按钮可达；公式可横向滚动；拍照/相册入口明显 |
| 768px | 两列/抽屉；表格可横向滚动 |
| 1366×768 | 首屏能看到主操作；侧边栏不挤压内容 |
| 1920×1080 | 内容最大宽度限制；不要拉满全屏 |

## 7. 页面验收清单

- [ ] 路由/权限正确。
- [ ] 主操作在首屏可见。
- [ ] loading/empty/error/success 四态齐全。
- [ ] AI 页面有 partial/retry。
- [ ] 三种题型可创建/显示/编辑；工具栏基础功能可用。
- [ ] 任务中心列表/状态/失败重试/草稿行可用；草稿双写可恢复。
- [ ] 练习 P0 可作答/计时/自评/记录；统计 P1 不阻塞。
- [ ] 长题干/公式/图片不溢出。
- [ ] 删除/重新生成有确认。
- [ ] 重复提交被阻止。
- [ ] 数据与 API 字段一致。
- [ ] 1366×768 和 375px 检查过。
- [ ] 对比度/焦点/键盘/标签检查过。
