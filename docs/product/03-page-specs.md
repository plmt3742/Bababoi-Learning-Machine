## 3. 示例：录入错题页（可照着填）

```text
页面名称：录入错题
路由：/questions/new
目的：让学生用最低成本把一道错题交给 AI 分析（文本或图片）
主操作：开始分析
次操作：切换输入方式、保存草稿、取消
布局：
  - 顶部：页面标题 + 返回
  - 输入方式：Tab「文本录入 / 图片识别」
  - 文本：题干输入区（大文本域）+ 答案（可选）
  - 图片：上传区 + 原图预览 + 可编辑识图结果
  - 右侧/下方：学科、标签
  - 底部：主按钮 + 提示
组件：PageHeader、Tabs、Form、Textarea、Select、TagInput、ImageInput、ImagePreview、Button、AIGenerationPanel
数据/API：
  - 文本：POST /questions → POST /questions/{id}/analyze
  - 图片：POST /uploads/images → POST /questions/from-image → 用户编辑 → POST /questions → analyze
状态：
  - loading：按钮 loading，表单禁用
  - vision：上传/识图中；显示进度 + 取消
  - empty：题干为空时主按钮禁用
  - error：识图/分析失败显示错误码 + 重试；保留输入
  - success：展示分析卡片 + “生成相似题”
交互：
  - 题干 ≤ 5000 字；答案 ≤ 5000 字；学科必选；标签 ≤ 10
  - 图片 JPEG/PNG/WebP，≤5MB；预览/删除/重拍
  - 手机：拍照、相册两个入口；无 HTTPS 时提示用相册/文本
  - 识图结果可编辑；用户确认后才创建错题
  - 分析中可取消；取消不创建重复错题
  - 离开页面时若有未保存内容，提示确认
校验：题干必填（或识图结果非空）、长度、学科必选、图片类型/大小
权限：登录用户
响应式：移动端单列；主按钮固定在底部；手机拍照/相册入口在首屏可见
验收标准：
  - 3 分钟内完成录入 + 分析（文本或图片）
  - 识图失败可重拍/换图/改文本，不丢输入
  - 重复点击不会创建多条错题
```

## 4. 关键页面要点

### 4.1 首页/概览

- 4 个核心数字：错题数、已练习数、正确率、连续练习天数（可选）。
- 薄弱知识点 Top 3 + “去练习”。
- 最近错题 3 条 + “查看全部”。
- 空状态：引导“录入第一道错题”。
- 不要堆 6 个图表；MVP 只保留 1 个趋势图或先不做图。

### 4.2 错题列表

- 筛选：学科、标签、关键词；URL 同步，可分享/刷新保留。
- 卡片：题干摘要（2–3 行）、学科、标签、生成题数、时间。
- 空状态 vs 筛选无结果要区分。
- 删除：二次确认；软删除；列表即时移除。
- 分页：默认 20；超过 100 条再考虑虚拟列表。

### 4.2b 图片录入（P0 增强）

- 电脑：拖拽/点击上传；显示原图预览、文件大小、删除/重拍。
- 手机：底部动作面板“拍照 / 从相册选择”；拍照用 `capture="environment"`。
- 识图：显示“正在识图”阶段；结果放在可编辑文本域，原图并排对照。
- 失败：重拍/换图/直接粘贴文本；不要只弹 toast。
- 含图题：显示“图形描述”，提示生成题以纯文本变体为主。

### 4.3 错题详情/生成

- 上方：原题 + 答案（折叠）+ 分析（知识点/题型/难度/错误原因）。
- 下方：3 张生成题卡；答案/解析默认折叠。
- 主操作：“生成相似题”；生成中显示阶段进度。
- 失败：错误说明 + 重试 + “返回编辑”。
- 已生成：可“重新生成”（P1）、“去练习”、“报错”。

### 4.4 练习

- 一次一道题；顶部进度（1/3）+ 计时。
- 作答区：文本域/选项（MVP 文本域 + 自评）。
- 提交后：显示答案 + 解析 + “会/不会”。
- 结果页：本次正确率、用时、薄弱点提示。
- 退出确认；重复提交禁用。

### 4.5 统计

- 4 个数字 + 1 个趋势图 + 薄弱点列表。
- 0 练习：空状态“先去练习 1 道题”。
- 数据口径与后端一致（正确率 = 正确数/总数）。
- 图表不要显示空坐标系；无数据时用空状态。

### 4.6 登录/注册

- 单页切换登录/注册；最少字段。
- 错误：用户名/密码错误、用户名已存在、网络错误。
- 登录成功跳 `redirect` 或首页。
- 不做找回密码/邮箱验证（P1）。

## 5. 通用状态规范

| 状态 | 表现 | 必须有 |
|---|---|---|
| loading | 骨架屏/按钮 loading | 不阻塞整个页面；可取消长请求 |
| empty | 插画/图标 + 一句说明 + 主操作 | 告诉用户下一步 |
| filter-empty | “没有符合条件的错题” + 清空筛选 | 不要和空账号混淆 |
| error | 错误说明 + 错误码（可选）+ 重试 | 不白屏；不丢输入 |
| partial | 已成功部分 + 失败提示 | 可重试缺失部分 |
| success | 明确结果 + 下一步 | 不要只弹 toast |

## 6. 响应式检查

| 宽度 | 检查 |
|---|---|
| 375px | 单列；底部导航；主按钮可达；公式可横向滚动；拍照/相册入口明显 |
| 768px | 两列/抽屉；表格可横向滚动 |
| 1366×768 | 首屏能看到主操作；侧边栏不挤压内容 |
| 1920×1080 | 内容最大宽度限制；不要拉满全屏 |

## 7. 页面验收清单

- [ ] 路由/权限正确。
- [ ] 主操作在首屏可见。
- [ ] loading/empty/error/success 四态齐全。
- [ ] AI 页面有 partial/retry。
- [ ] 长题干/公式/图片不溢出。
- [ ] 删除/重新生成有确认。
- [ ] 重复提交被阻止。
- [ ] 数据与 API 字段一致。
- [ ] 1366×768 和 375px 检查过。
- [ ] 对比度/焦点/键盘/标签检查过。
