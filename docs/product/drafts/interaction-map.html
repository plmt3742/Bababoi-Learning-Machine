状态机摘要

QEDIT-01
draft → editing → detecting → confirming → vision → editing → saving → saved；任一阶段失败 → error（保留草稿）；整页/无 candidate → vision（整图识图）
TASK-01
queued → running → done / failed；failed → queued（重试）；同一 question + stage 只允许一个 active task
QDETAIL-01
loading → analysis_pending → generated / partial；partial → generated（重试缺失）；error → loading
PRACTICE-01
unanswered → answered → revealed → result；answered → submit_failed → answered（重试）

框题确认（P0）

图片 → AI 检测 → 有 candidate：高亮 top-1，用户确认/切换、移动/缩放 AI 框、重置整图； 第二阶段传 candidate_index + 可选 crop_box（归一化，传了优先）。 AI 判定整页 → 整页识别不框；无 candidate / grounding 不可用 → 整图识别。 从零画框为 P1。
