使用

  • 48px 及以下使用纸面标记；状态表情建议 ≥ 120px。
  • 平面资产透明背景，无外链字体、位图和渐变。
  • 3D 页使用 serve.cmd 启动静态服务器；不要用 file:// 直接打开。
  • 3D 页支持拖动旋转、滚轮缩放、双击复位。
  • 状态切换有轻弹动；标记循环动画尊重 prefers-reduced-motion。
  • 3D 的层级来自几何、蓝边和粗墨线，不使用阴影或高光。
