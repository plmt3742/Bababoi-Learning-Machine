为什么是平面 3D

01 / REAL 3D

卡片是真的几何体

卡片用 ExtrudeGeometry 挤出 0.24 厚度，正面/背面/侧边是不同材质；拖动是相机绕物体旋转，不是 CSS 倾斜图片。

02 / CEL

2D 表情 + 3D 体积

正面表情是一张 1024×1219 的纯平涂贴图：没有阴影、渐变和高光。体积由纯色蓝侧边、挤出厚度和粗墨线轮廓提供。

03 / THICKNESS

不同层级不同厚度

0.24 挤出卡片 + 平涂蓝色折角 + 纯色蓝边 + 内嵌正面贴图 + 粗墨线轮廓；去掉所有投影后，靠几何和黑边表达厚度。

空闲轻摆、指针视差、状态切换轻弹；思考泡泡循环上浮、问号旋转、星星循环出现、失败水滴下落。系统开启减少动态时自动停用。Three.js r170（MIT）以本地 vendor 存放，页面离线可开；这是设计演示，不进入应用包。平面 Calm Academic 版仍在 mascot-states.html。未改应用代码。
