### 0.3 通用状态

| 状态 | 表现 | 必须 |
|---|---|---|
| loading | 骨架屏 / 按钮 loading | 不阻塞整页；长请求可取消 |
| empty | 说明 + 主操作 | 告诉用户下一步 |
| filter-empty | “没有符合条件的记录” + 清空筛选 | 不和“空账号”混淆 |
| error | 错误说明 + 错误码 + 重试 | 不白屏；不丢输入 |
| partial | 已成功部分 + 失败提示 | 可重试缺失部分 |
| success | 明确结果 + 下一步 | 不只弹 toast |

## 1. AUTH-01 登录/注册（P0）

**目的**：进入产品；建立 JWT 登录态。
**路由**：`/login`
**主操作**：登录 / 注册

```text
┌────────────────────────────────────────────┐
│  产品名                                     │
│                                            │
│      ┌──────────────────────────────┐      │
│      │ [登录] [注册]                 │      │
│      │ 用户名  [__________________]  │      │
│      │ 密码    [__________________]  │      │
│      │                              │      │
│      │ [          登录          ]   │      │
│      │ 错误提示区                    │      │
│      └──────────────────────────────┘      │
│                                            │
│  说明：P0 不做找回密码 / 邮箱验证            │
└────────────────────────────────────────────┘
```

**关键组件**：`AuthCard`、`Tabs`、`Form`、`Input`、`Button`、`InlineError`、`Toast`。
**数据流入**：`redirect`（可选）、空表单。
**数据流出**：`access_token`、`token_type`、`user` → auth store；后续请求带 `Authorization: Bearer <JWT>`。
**状态**：idle / submitting / error（401、409、网络）/ success。
**跳转**：成功 → `redirect` 或 HOME-01；已登录 → HOME-01。
**示例**：用户名 `student01`，密码 ≥8 位；错误提示“用户名或密码错误”。

**目的**：给用户一个入口聚合页：录入、任务、最近错题、练习。
**路由**：`/`
**主操作**：录入错题

```text
│ └──────────────────────────────────────────────────────────┘ │
│                                                              │
│ 最近错题（3 条）                                   [全部]   │
│ ┌──────────────────────────────────────────────────────────┐ │

│ └──────────────────────────────────────────────────────────┘ │

```

**关键组件**：`AppShell`、`PageHeader`、`QuickActions`、`TaskRow`、`QuestionCard`、`StatsStrip`（P1）、`EmptyState`。

**示例**：最近错题展示 2–3 行题干摘要，公式用行内 LaTeX；不展开答案。

## 4. QEDIT-01 录入/编辑（P0）

**目的**：文本/图片录入 → 用户裁剪 → AI 提取多题文本 → 逐条确认 → 编辑 → 保存；同时管理草稿。
**路由**：`/questions/new`；编辑用 `/questions/:id/edit`
**主操作**：保存
**P0 增强**：三种题型 + 工具栏；图片上传前裁剪；提取结果按 ① ② ③ … 条目展示；当前阶段只提取文本。

```text
┌──────────────────────────────────────────────────────────────┐
│ 录入/编辑        [草稿：未同步/已同步]        [取消] [保存]  │
├──────────────────────────────────────────────────────────────┤
│ 输入方式：[文本] [图片]        题型：[选择][填空][解答]      │
├──────────────────────────────────────────────────────────────┤
│ 题干                                                          │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 求函数 $f(x)=x^3-3x+1$ 的极值。                          │ │
│ └──────────────────────────────────────────────────────────┘ │
│ 工具栏：[B][I][U] [列表] [LaTeX 模板 v] [编号 v] [表格][图] │
│                                                              │
│ 选择题：选项 A–D / 增删 / 单选多选                            │
│ 填空题：题干中的 ___ / 每个空的答案                           │
│ 解答题：答案 / 解析                                           │
├──────────────────────────────────────────────────────────────┤
│ 右侧：学科 [高数 v]  章节 [导数 v]  标签 [导数][极值] +      │
│                                                              │
│ 图片模式：                                                    │
│ ┌──────────────────────────────┐  ┌─────────────────────────┐ │
│ │ 原图预览 + 裁剪器             │  │ 识别结果（N 道题）        │ │
│ │ [裁剪] [重置原图]             │  │ ① 题干… [编辑][删除]     │ │
│ │                              │  │ ② 题干… [编辑][删除]     │ │
│ │                              │  │ ③ 题干… [编辑][删除]     │ │
│ │                              │  │ [确认并创建] [重拍]       │ │
│ ├──────────────────────────────┤  ├─────────────────────────┤ │
│ │ 确认后：每道题显示答案/解析   │  │ ☑ ① 题干… 答案/解析      │ │
│ │                              │  │ ☑ ② 题干… 答案/解析      │ │
│ │                              │  │ ☐ ③ 题干… 答案/解析      │ │
│ │                              │  │ [生成相似题（2）]         │ │
│ └──────────────────────────────┘  └─────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

**题型结构**：

| 题型 | 必填 | 结构 |
|---|---|---|
| 选择题 | 题干、≥2 个选项 | `options: [{label, content_md}]`；单选/多选 |
| 填空题 | 题干、每个空答案 | `blanks: [{index, answer_md}]`；空位 ≤20 |
| 解答题 | 题干 | `answer_md` / `explanation_md` 可选 |

**关键组件**：`QuestionEditor`、`EditorToolbar`、`QuestionTypeSwitcher`、`OptionEditor`、`BlankEditor`、`ImageInput`、`ImageCropper`、`RecognizedQuestionList`、`RecognizedQuestionItem`、`DraftBar`、`MarkdownRenderer`、`SaveBar`。
**数据流入**：
- 编辑：`GET /questions/{id}`
- 草稿：`GET /drafts/me` + localStorage
- 图片：`POST /uploads/images`（裁剪后）→ `POST /questions/from-image`（返回 `questions[]`，1..N 道）
**数据流出**：
- 保存：确认后的每道题 `POST /questions`（`content_md`、`answer_md`、`explanation_md`、`question_type`、`options`、`blanks`、`subject`、`chapter`、`tags`、`source_type`、`image_path`）→ 每道 `question + task_id`
- 草稿：`PUT /drafts/me`（防抖 5s）、`DELETE /drafts/me`
**状态**：draft / cropping / uploading / extracting / confirming_items（逐条编辑/删除）/ editing / saving / saved / error。
**跳转**：保存成功 → TASK-01 或 QDETAIL-01；取消 → 三选项（取消退出 / 保存草稿 / 直接退出）；图片提取失败 → 退回文本。
**多题选择/生成**：确认创建后，每道题展示答案/解析；勾选 1–3 道（选中高亮）→【生成相似题】；每个选中题目独立生成 3 道相似题，任务在任务中心/详情查看。
**示例**：
- 高数：求 `f(x)=x^3-3x+1` 的极值
- 线代：设 `A=[[1,2],[2,1]]`，求特征值
- 概率：设 `X~N(0,1)`，求 `P(|X|≤1.96)`
- 大学物理：`v(t)=3t^2-2t`，求 `t=2s` 时加速度

> 工具栏为 P0 增强；表格/插入图片/复杂编号可按时间降级到 P1。KaTeX 错误标红，不丢内容。

## 5. TASK-01 任务中心（P0）

**目的**：看录入记录、后台整理/生题状态、失败重试、草稿入口。
**路由**：`/tasks`
**主操作**：继续编辑 / 重试

```text
┌──────────────────────────────────────────────────────────────┐
│ 任务中心                                                     │
├──────────────────────────────────────────────────────────────┤
│ 草稿行：求函数 f(x)=x^3-3x+1 的极值 · 11-05 22:10 [继续编辑]│
├──────────────────────────────────────────────────────────────┤
│ 题目摘要            整理      生题        时间       操作    │

│ 设 A=[[1,2]...]     生成中    排队中      22:12      [查看]  │
```

**数据流出**：`POST /tasks/{id}/retry`；`GET /questions/{id}` → QDETAIL-01；草稿 → QEDIT-01。
**状态**：queued / running / done / failed；空列表。
**跳转**：行 → QDETAIL-01；失败 → 原地重试；草稿行 → QEDIT-01。
**说明**：P0 不做复杂筛选/通知/批量操作。


**关键组件**：`StatCard`、`WeakPointList`、`TrendChart`（ECharts，P1）、`EmptyState`。
**数据流入**：`GET /stats/overview`、`GET /stats/weak-points?limit=5`、`GET /stats/trends?days=30`。
**数据流出**：点击知识点 → QLIST-01（按 tag 筛选）或 PRACTICE-01。
**状态**：loading / empty（无练习）/ error。
**跳转**：薄弱点 → QLIST-01 / PRACTICE-01；返回 → HOME-01。
