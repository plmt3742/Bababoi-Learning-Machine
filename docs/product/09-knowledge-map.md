# 09 · 知识脉络与掌握地图（设计稿）

> 状态：设计稿，未进入开发。视觉稿：[`drafts/knowledge-map.html`](drafts/knowledge-map.html)（可直接双击打开）。
> 目标：把错题里的知识点从“标签列表”升级成“可解释的复习路线”，让学生知道**先补什么、为什么**。

## 1. 入口与定位

- 入口：首页「学习概览」→ 知识脉络；也可从统计页的「薄弱知识点」进入。
- 定位：不是知识图谱编辑器，也不是课程目录；只回答三个问题：
  1. 我哪些知识点没掌握？
  2. 它们之间的前置关系是什么？
  3. 下一步先练哪一个？
- 非目标：LLM 自动生成整张学科图谱、节点自由拖拽编辑、跨用户共享。

## 2. 页面结构

```text
AppShell 顶栏（首页 / 错题本 / 录入错题 / 任务中心 / 知识脉络）
└─ 页面标题：KNOWLEDGE MAP · 知识脉络
   ├─ 4 个概览数字：覆盖知识点 / 已掌握 / 复习中 / 未掌握
   ├─ 左侧：掌握地图
   │  ├─ 视图切换：掌握 / 脉络；筛选：全部学科、只看薄弱
   │  ├─ SVG 节点图：颜色 = 掌握度，连线 = 前置关系
   │  ├─ 右上角当前节点卡：名称、状态、错题数、前置、去练习
   │  └─ 图例：已掌握 / 复习中 / 未掌握 / 未接触
   └─ 右侧：建议复习路径 + 最需要补的 3 个点 + 数据说明
```

### 视觉规则（沿用 Calm Academic）

- 纸面白 + hairline 边框 + 单一 Arco 蓝；节点用浅底 + 深色描边，不使用大面积渐变。
- 掌握度不能只靠颜色：节点内显示文字状态，图例 + 列表视图作为无色彩替代。
- 节点大小保持稳定，错题数放在右侧小圆徽章；当前节点用蓝色虚线圈，不用放大。
- 连线只表达“前置 → 后继”，不表达“包含/相关”；避免在一张图里混多种关系。

## 3. 交互

| 动作 | 结果 |
|---|---|
| hover / 键盘 focus 节点 | 节点浮起；右上角详情卡切换到该节点 |
| 点击节点 | 保持选中；详情卡显示“去练这一块” |
| 点击「去练这一块」 | 进入练习或错题本，按该知识点标签过滤（`/questions?tag=极值`） |
| 「只看薄弱」 | 只保留未掌握/复习中节点，隐藏未接触节点 |
| 「列表视图」 | 按掌握度排序的知识点列表，含错题数、正确率、前置；移动端默认列表 |
| 节点过多 | 按学科分簇；默认只展开当前学科，其他簇折叠为入口 |

移动端：地图高度降到 430px，详情卡移到图下方；节点可点，不依赖 hover；默认提供列表视图入口。

## 4. 数据与接口（提案）

```http
GET /api/v1/stats/knowledge-map?subject=高等数学&weak_only=false
```


### 数据来源（MVP）

- 节点：`questions.tags` 的知识点名（与「薄弱知识点」同一来源）。
- 掌握度：优先用 `questions.mastery_status`；没有练习记录时为“未接触”；有练习但正确率不稳定为“复习中”。
- 错题数：该标签下的错题数；练习数/正确率来自 `practice_records`。
- 连线：**静态前置关系表**（先覆盖大学理科高频知识点，如极限→连续→导数→单调性→极值）。本期不用 LLM 生成。
- 建议路径：按“已掌握的前置 → 当前薄弱节点”做拓扑排序，取第一条未掌握路径。

### 降级与空态

- 没有标签或数据不足：不画空图，直接显示「薄弱知识点列表」+ “先去录入错题”。
- 节点超过 30 个：按学科分簇，默认只展开一个簇。
- 图数据接口失败：显示列表视图 + 重试，不影响统计页其他卡片。

## 5. MVP 范围与排期

| 项 | 说明 | 优先级 |
|---|---|---|
| 知识地图页 + SVG 节点图 | 静态前置表 + 现有标签聚合 | P1 |
| 列表视图 | 无图/移动端兜底 | P1 |
| 节点详情 + 去练习 | 复用错题本标签筛选 | P1 |
| 前置关系维护 | 先内置一份 30–50 个知识点的表，后续可配置 | P1 |
| 自动生成图谱 / 编辑 | 不做 | P2 |

## 6. 待确认

1. 前置关系表由谁维护（产品/后端），先覆盖哪些学科？
2. 「掌握」阈值是否沿用现有 `mastery_status`，还是按正确率重新计算？
3. 标签同义词（导数/求导、极值/最值）是否需要合并规则？
4. 节点点击后的练习入口：按标签筛错题，还是生成一组专项练习（会牵涉生成 API）？
