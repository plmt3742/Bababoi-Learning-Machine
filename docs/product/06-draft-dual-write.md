# 06 · 草稿：服务端 + localStorage 双写

> owner: 霹雳马桶 · last_updated: 2026-11-05 · read_when: 实现录入页草稿、联调 `/drafts/me`、排查草稿冲突
> 来源：2026-11-05 草稿双写决策 + `02-ia-and-flows.md` / `03-page-specs.md`

## 1. 一句话

**服务端草稿负责跨设备恢复，localStorage 负责断网/崩溃兜底；两边都写，恢复时取更新时间较新的一份。**

## 2. 为什么要双写

| 方案 | 问题 |
|---|---|
| 只存 localStorage | 换电脑/换浏览器就丢；无法跨设备 |
| 只存服务端 | 断网、崩溃、请求失败时，最后一次输入可能丢 |
| 双写 | 本地实时兜底 + 服务端跨设备；代价是要处理冲突 |

## 3. 数据与 API

### 3.1 服务端表

```text
draft
- id
- user_id UNIQUE
- content_json      # 编辑器完整状态：题型/题干/选项/空位/答案/标签
- version           # 乐观锁，每次 PUT +1
- updated_at
```

每个账号 **1 份**草稿；再次保存覆盖旧草稿。

### 3.2 接口

```text
GET /api/v1/drafts/me
→ 200 { content: {...}, version: 3, updated_at: "..." }
→ 204 无草稿

PUT /api/v1/drafts/me
← { content: {...}, base_version: 3, client_updated_at: "..." }
→ 200 { content, version: 4, updated_at }
→ 409 版本冲突（不回传服务端草稿；前端收到 409 后自行 GET 最新，再提示选择保留哪份）

DELETE /api/v1/drafts/me
→ 204（保存入库/主动放弃后清理）
```

## 4. 前端写入规则

### 4.1 本地

- 每次内容变更：**立即写 localStorage**，key：`bababoi:draft:{userId}`。
- 存储内容：`{ content, client_updated_at, server_version }`。
- 退出登录/切换账号：清空当前账号的本地草稿 key，避免串号。

### 4.2 服务端

- 内容变更后 **防抖 5s** 调 `PUT /drafts/me`。
- 请求失败：保留本地草稿，标记 `pending_sync=true`；下次进入/联网时重试。
- 保存入库成功后：调 `DELETE /drafts/me`，并清本地草稿。

## 5. 恢复规则

进入录入页时：

1. 读本地草稿 + `GET /drafts/me`。
2. 两边都没有 → 空白编辑器。
3. 只有一边 → 提示“有未完成的草稿，继续编辑？”。
4. 两边都有 → 比较 `updated_at`：
   - 服务端较新 → 用服务端；
   - 本地较新 → 用本地，并提示“本地有更新，是否同步到服务端？”；
   - 时间相同 → 用服务端。
5. 恢复后，用户可继续编辑或点【放弃草稿】。

## 6. 退出规则

用户点【取消】/关闭录入页/切换录入方式时，弹三选项：

```text
取消退出
保存为草稿后退出（立即同步服务端）
直接退出（不保存）
```

- 保存为草稿：立即 `PUT /drafts/me`，不等 5s 防抖。
- 直接退出：清本地草稿 + `DELETE /drafts/me`。
- 取消退出：留在当前页。

## 7. 冲突与边界

| 场景 | 处理 |
|---|---|
| 两个标签页同时编辑 | `version` 乐观锁；409 时提示“另一处有更新”，让用户选择保留本地/服务端 |
| 断网编辑 | 本地照写；联网后重试 PUT；不阻塞编辑 |
| 保存入库成功但 DELETE 草稿失败 | 下次进入时服务端草稿仍在；前端提示“已保存，是否清理草稿？” |
| 换账号 | 按 userId 隔离 localStorage key；退出时清理 |
| 草稿过大 | 限制 `content` 序列化后 ≤ 256KB（`DRAFT_MAX_BYTES`）；超出提示精简内容 |
| 隐私 | 草稿只存题目内容，不存密码/token；日志不打印全文 |

## 8. 验收清单

- [ ] 编辑 5s 后服务端有草稿。
- [ ] 断网编辑，刷新后本地草稿还在。
- [ ] 换浏览器登录，能恢复服务端草稿。
- [ ] 两边都有草稿时，取更新时间较新的一份。
- [ ] 两个标签页同时编辑，409 有提示，不静默覆盖。
- [ ] 保存入库后草稿被清理。
- [ ] 退出登录后本地草稿不串号。
- [ ] 草稿内容含题型/选项/空位/答案/标签，恢复后编辑器状态完整。
