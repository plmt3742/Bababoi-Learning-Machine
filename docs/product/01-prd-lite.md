# 01 · PRD-lite

> 目标：一页纸讲清“给谁、解决什么、怎么用、先做什么”。45 分钟内填完，不要写成大创申报书。

## 1. 一句话

把一道错题变成三道同类题，并追踪掌握度的 AI 错题巩固平台。

## 2. 目标用户与场景

| 项 | 内容 |
|---|---|
| 主用户 | 大学理科生（高数/线代/概率论/大学物理为主） |
| 具体画像 | [大二理工科、成绩区间、错题习惯；电脑上传图片，手机拍照/相册] |
| 使用场景 | [课后作业、期中/期末复习、错题集中整理] |
| 现有替代 | [手抄错题本、拍照搜题、题库 App、Excel] |
| 现有不足 | [耗时、只会一道题、没有同类练习、没有掌握度] |

## 3. 用户问题（最多 3 个）

1. [错题整理耗时，难以坚持]
2. [看懂了原题，换个情境又不会]
3. [不知道哪个知识点反复错，复习没重点]

## 4. 核心闭环（≤ 5 步）

```text
录入错题（文本/图片）→ AI 分析 → 生成 3 道相似题 → 练习 → 统计薄弱点
```

每一步的用户动作、系统反馈、失败兜底：

| 步骤 | 用户动作 | 系统反馈 | 失败怎么办 |
|---|---|---|---|
| 录入（文本） | 粘贴题干/可选答案/选学科 | 校验、保存 | 提示错误；保留输入 |
| 录入（图片） | 电脑上传；手机拍照/相册 | DeepSeek 识图，结果可编辑 | 重拍/换图/改文本；不丢输入 |
| 分析 | 点击“开始分析” | 阶段进度 + 知识点/题型/错误原因 | 重试；不丢输入 |
| 生成 | 点击“生成相似题” | 3 张题卡 + 答案/解析 | 重试/重新生成 |
| 练习 | 作答、提交、自评 | 对错 + 解析 + 记录 | 提交失败可重试 |
| 统计 | 查看首页/统计页 | 正确率、薄弱知识点、趋势 | 空状态引导去练习 |

## 5. 范围

### P0（演示必须）

- [ ] 最小登录
- [ ] 文本录入错题
- [ ] 图片录入（P0 增强）：电脑上传 / 手机拍照/相册；DeepSeek 识图；结果可编辑
- [ ] AI 分析
- [ ] 生成 3 道相似题
- [ ] 错题列表/详情/编辑/删除
- [ ] 学科/标签筛选 + 搜索
- [ ] 练习 + 记录
- [ ] 学习概览
- [ ] 部署 + 种子数据

### P1（有余力）

- [ ] 重新生成/质量反馈
- [ ] 导出
- [ ] 复习提醒
- [ ] 移动端其余页面适配
- [ ] token 级流式
- [ ] 多图/批量上传

### P2（不做）

- [ ] 知识图谱
- [ ] 模型训练
- [ ] 复杂推荐
- [ ] 社区/教师端/付费

### 非目标

- 不做拍照解题/答案搜索
- 不做完整后台
- 不做需要标注数据/训练的功能

## 6. 成功指标（最多 3 个）

| 指标 | 目标 | 怎么测 |
|---|---|---|
| 核心闭环完成时间 | < 3 分钟 | 可用性测试 |
| 生成题可作答率 | ≥ 80% | 人工抽检 20 组 |
| 识图可用率（大学理科含图/公式） | ≥ 80% | 人工抽检 10 张 |

## 7. 关键假设

1. [用户愿意粘贴文本，或上传/拍摄图片；识图结果允许修正]
2. [DeepSeek API 稳定，文本+图片成本可控]
3. [评审更看重闭环完成度而非功能数量]

## 8. 最大风险（最多 3 个）

1. [范围过大，25 天做不完] → 砍 P1/P2
2. [AI 输出不稳定/答案错误] → 校验 + 重试 + 抽检
3. [部署/演示翻车] → 11.14 staging + 缓存/录屏兜底

## 9. 开放问题

| 问题 | 选项 | 建议 | 截止 |
|---|---|---|---|
| 演示学段/学科 | 高中理科/大学 | **大学理科（已定）** | 11.5 |
| 登录范围 | 完整/最小/不做 | 最小 JWT | 11.5 |
| 图片录入 | 独立 OCR / 多模态识图 / 不做 | **不做独立 OCR；DeepSeek `deepseek-flash` 识图；P0 增强** | 11.5 |
| 流式粒度 | token/阶段 | 阶段级 | 11.7 |

## 10. 一句话验收

一个没听过项目的人，看完演示能说出：**“它把错题变成同类题，并告诉我哪个知识点没掌握。”**
