## 设计评审清单

- [ ] 3 分钟能讲完核心闭环。
- [ ] 每页一个主操作。
- [ ] 每个异步动作有 loading/success/error。
- [ ] 每个列表有 empty/filter-empty/loading/error。
- [ ] 每个删除/重新生成有确认。
- [ ] 每个 AI 失败有重试/取消。
- [ ] 375/768/1366/1920 四档检查。
- [ ] 真实长题干 + 公式 + 图片检查。
- [ ] 对比度/焦点/键盘/标签检查。
- [ ] 设计元素能映射到 Arco 组件。
- [ ] 每个数据块能映射到 API。
- [ ] 没有 P2 功能混进 P0。
