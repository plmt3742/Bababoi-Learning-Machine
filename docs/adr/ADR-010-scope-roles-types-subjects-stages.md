# ADR-010: 范围边界——角色、题型、学科、学段

- 状态：Accepted
- 日期：2026-11-27
- 决策人：人机（产品边界；涉及前端渲染的部分与霹雳马桶同步）
- 相关任务：BE-030（管理员重置密码）
- 相关文档：`ADR-002`、`ADR-005`、`ADR-009`（admin 演示范围，进行中）、`Q-001`、`Q-002`

> 2026-11-27 补正：§2.1 的密码重置按「学生线上申请 → 管理员审批 → 系统重置」定稿流程修订（以 `docs/agent/28-admin-console.md` 为准，PR #116）；§2.2 多选说明改为「当前仍单选」。

## 1. 背景

「管理员重置密码」把 admin 从只读运维台推到了会改用户数据的角色；同时演示前后反复被问到
题型、学科、学段能不能扩。这三类问题如果不写死边界，每次讨论都会重新摇摆。本 ADR 只定
**边界与扩展条件**，不排期。

## 2. 决策

### 2.1 角色

- 账号角色**只有 `student` / `admin`**。不做 teacher / 家长 / 多角色 RBAC。
- `admin` 是内部运维角色（ADR-005）：账号由环境变量初始化，**不开放注册**；学生端注册只会产生 `student`。
- 鉴权：`require_admin` **每次查 DB 角色**（不信 token claim）；学生 token 访问 `/api/v1/admin/*` 一律 403。
- **线上密码重置（定稿流程，详见 `docs/agent/28-admin-console.md` §5，PR #116）**：
  1. 学生登录页 → `/forgot-password`，提交 `username` + 可选 `email` + 原因；未登录可访问；按 IP/用户名限流；同一用户已有 pending 申请则拒绝；响应不泄露用户名是否存在。
  2. 管理员在 admin 审批队列通过 / 拒绝。
  3. 通过后由**系统生成**临时密码（约 12 位、去易混淆字符；只在管理端显示一次，`Cache-Control: no-store`）：写 bcrypt、`must_change_password=true`、`temp_password_expires_at=now+24h`、目标 `token_version+1`（全踢）、写审计——审计与重置同一事务，审计失败则回滚。
  4. 学生用临时密码登录（响应 `must_change_password=true`），改密前只允许改密/登出；改密后清标记与过期时间、`token_version` 再 +1、写审计，用新密码重新登录。
  5. 临时密码 24h 有效，过期后登录与业务接口都拒绝，需重新申请；管理员忘记只能重新生成，旧临时密码立即失效。
- 不做：管理员**无条件直接重置**、邮件/短信通知、学生自助领取/状态页、模拟登录、直接改库、批量导出个人数据。
- 不新增姓名/学号字段：申请只用 `username` + 可选 `email` + 原因。
- 数据结构：`password_reset_requests`（申请/审批）与 `admin_audit_logs`（审计），随 BE-030 迁移。

### 2.2 题型

- 当前与演示保持三种：`solve` / `choice` / `blank`。
- **不新增枚举值**：
  - 判断题 = 2 个选项的 `choice`；
  - 多选题可以用 `choice` + `options` 列表表达，但**当前练习页仍是单选（radio）**；将来做多选需前端渲染与判分一起改，schema 可加**可选字段**，不改表。
- 证明题 / 作图题 / 需要过程判分的题**不做**：现有模型无法可靠校验。
- 扩展条件：prompt、validator、前端渲染**三处同时改**，缺一不可；扩展本身不需要迁移。

### 2.3 学科

- `subject` 保持**自由字符串**（`VARCHAR(32)`），不做枚举、外键、知识点体系。
- 当前演示固定大学理科四门：高等数学 / 线性代数 / 概率论 / 大学物理。
- 新增学科**零迁移**：改 prompt 示例 + 补种子数据 + 前端学科选项即可，API 形状不变。

### 2.4 学段

- **不新增 `stage` 列/枚举**，当前定位大学理科（Q-001）。
- 扩展到高中/初中时：优先用 `subject` 命名区分（如「高中物理」）；确需按学段筛选，再加**可选** `stage` 列（前向迁移，默认 NULL），不改现有必填字段与 API。
- 不做教材版本、课程体系、多学段内容运营。

## 3. 影响

- 题型/学科/学段：**无迁移、无 API 形状变化**；只约束 prompt、种子与前端选项。
- 角色：线上密码重置需要 `users.role`、`password_reset_requests`、`admin_audit_logs`、`must_change_password` 等字段，随 BE-030 单独迁移；学生端不受影响。
- 新扩展的验收口径：先过本 ADR 的边界，再谈实现。

## 4. 明确不做

- 教师端、班级/作业、家校沟通、多租户、付费。
- 多题型富编辑器、知识点图谱、学段配置中心。
- 邮箱自助找回（维持 Q-002：管理员授权）。
