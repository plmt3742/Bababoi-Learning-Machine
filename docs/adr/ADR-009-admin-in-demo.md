# ADR-009: 管理端进入 11.29 演示

- 状态：Accepted
- 日期：2026-11-27
- 决策人：霹雳马桶、人机
- 相关任务：ADM-001 ~ ADM-012
- 相关文档：`docs/agent/28-admin-console.md`、`docs/adr/ADR-005-admin-console.md`、`docs/agent/04-todos.md`

## 1. 背景

ADR-005 曾决定 `admin/` 只做 P1 内部运维台，不进入 11.29 学生演示关键路径。现在管理端需要作为演示的一部分，展示系统监控、AI 质量/成本、任务队列与审计能力；同时线上密码重置申请/审批也需要管理端承载。

当前 `admin/` 只有 README，后端还没有 `users.role`、`admin_audit_logs`、`password_reset_requests` 等基础。管理端进入演示会带来额外工作量，必须限定演示范围，避免挤占学生端 P0。

## 2. 决策

**管理端进入 11.29 演示；ADR-005 中“不进入 11.29 演示”的范围决策由本 ADR 取代，其余决策继续有效。**

演示范围按优先级：

| 优先级 | 内容 |
|---|---|
| 必须 | 管理员登录/403 边界、总览、任务列表/详情、AI 调用日志、审计列表、系统健康 |
| 目标 | 线上密码申请 + 管理员审批 + 临时密码 24h + 学生强制改密 |
| 演示后 | 内容标记/质量队列、导出、告警中心、批量操作、只读 auditor、完整审计保留策略 |

约束：

- 演示只展示已实现的能力；未完成项在 PPT 中标注为规划，不伪装为已上线。
- 学生端 P0 仍优先；管理端基础（role/audit）不得阻塞学生端演示。
- 管理端是独立 `admin/` 应用，使用 `/api/v1/admin/*` 与 `require_admin`，不放进学生端。
- 线上密码重置使用正常注册字段（username/可选 email/password），不新增姓名/学号。
- 临时密码只在管理端显示一次，24h 有效，学生登录后强制改密；不做邮件/短信通知、学生状态页。

## 3. 后果

### 正面

- 演示可以展示“学生端闭环 + 管理端监控/审计”的完整工程故事。
- 监控、审计、AI 成本与任务排障有统一入口。
- 密码重置从线下核验改为线上申请 + 管理员审批，流程可演示、可留痕。

### 负面/代价

- 11.29 前需要额外完成 `users.role`、`disabled_at`、`admin_audit_logs`、`password_reset_requests` 和管理端登录/总览。
- 对两人团队是额外前端应用、CI job 和部署路径。
- 若基础未按时完成，只能演示只读部分；不能为了演示跳过审计或权限。

### 风险与缓解

| 风险 | 缓解 |
|---|---|
| 范围蔓延成完整后台 | 以 28 号文档的模块清单为准；演示只做只读 + 密码申请 |
| 挤占学生端 P0 | 管理端基础不得影响学生端构建/回归；先做 role/audit 再谈页面 |
| 权限绕过 | `require_admin` 查 DB；学生 token 403；测试 401/403 |
| 误删数据 | 所有删除软删；审计与写操作同事务 |
| 临时密码泄露 | 只显示一次；不写日志/审计/数据库明文；24h；强制改密 |
| 管理端/学生端 session 互踢 | 独立 token key、独立登录页 |

## 4. 备选方案

| 方案 | 优点 | 缺点 | 为什么没选 |
|---|---|---|---|
| 维持 ADR-005：只在 PPT 展示 | 不占开发时间 | 无法现场展示监控/审计；与当前目标不符 | 用户明确要求进入演示 |
| 完整管理端全部进演示 | 功能完整 | 2 天内不可行，挤占学生端 P0 | 范围过大 |
| 只做学生端内嵌管理页 | 构建简单 | 权限/登录态边界模糊 | 与 ADR-005 独立应用决策冲突 |

## 5. 验收

- 学生 token 访问 `/admin/*` 返回 403；admin token 返回 200。
- 总览数字与 DB 一致；AI 成功率/延迟/失败任务与 `ai_call_logs`、`generation_task` 一致。
- 任务/AI 日志只读页面可用；敏感字段不返回。
- 审计列表可见管理员登录/关键操作；写操作审计失败回滚。
- 密码申请（若演示）：提交、审批、临时密码 24h、学生强制改密、旧会话失效。
- 管理端构建进入 CI；学生端构建与 11.29 演示脚本不受影响。
